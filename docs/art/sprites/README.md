# Sprites Silken Hell

Génération : outil intégré imagegen (built-in), septembre 2026. Référence de style : sprite original spider_down du jeu. Les PNG transparents sont conservés sans retouche ; art.lua recadre leur alpha au rendu, avec filtrage nearest.

## Prompts utilisés

### raven.png

Use case: stylized-concept. Production PNG game sprite for Silken Hell. Create ONE boss raven, frontal 3/4 overhead dungeon-game view, wings spread symmetrically, feet visible, white-gold small eyes and beak, charcoal indigo-black plumage, sparse antique-gold celestial details. Match the reference's chunky low-resolution dark fantasy pixel art, blocky pixel clusters and thick dark stepped silhouette, 32-bit retro rendered sprite, no smooth vector style. Entire raven centered with generous transparent padding, no floor, no environment, no shadow plane, no text, no frame, genuinely transparent alpha background. The raven is a stationary central arena boss, readable when rendered 140 pixels wide. Reference image is STYLE ONLY, do not create a spider.
